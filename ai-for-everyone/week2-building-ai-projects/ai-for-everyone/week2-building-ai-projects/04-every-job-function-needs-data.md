# Week 2 — Every Job Function Needs to Learn How to Use Data

> Course: **AI for Everyone** by Andrew Ng (DeepLearning.AI / Coursera)
> Week: **2 — Building AI Projects** · Lesson: **Every job function needs to learn how to use data**
> Study notes (original summary, not verbatim transcript).

## Core Idea
Data literacy is no longer only for analysts. Every function — marketing, finance, HR, operations, product — benefits from being able to read and question data, because decisions increasingly rest on it.

## Key Points
- **Data is now everyone's job**: marketing, sales, finance, HR, and operations all make data-driven decisions; employees who can use data add outsized value.
- **Two complementary skills**:
  - **Data science skills** — extracting insights to inform decisions.
  - **ML skills** — building systems that automate tasks.
  - Most employees need a degree of **data literacy** (reading, interpreting, questioning data), not necessarily the ability to build models.
- **Bridging the gap**: a single data science team is not enough; the organization must help non-technical staff **ask good questions of data** and understand basic analyses.
- **For leaders**: investing in data training across functions compounds into better products and faster decisions company-wide.

## Takeaways
- Treat data literacy as a **universal, ongoing skill** in the org, not a specialist-only one.
- Everyone should be able to ask, "does this data actually support that conclusion?"
- Broad data fluency makes AI and analytics initiatives far more effective.
