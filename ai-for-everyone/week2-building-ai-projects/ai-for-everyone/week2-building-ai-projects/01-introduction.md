# Week 2 — Building AI Projects: Introduction

> Course: **AI for Everyone** by Andrew Ng (DeepLearning.AI / Coursera)
> Week: **2 — Building AI Projects** · Lesson: **Introduction**
> Study notes (original summary, not verbatim transcript).

## Core Idea
Week 2 shifts from "what AI can do" to "how AI projects are actually built" — the workflow, the team, and how to pick a project that is both technically feasible and valuable.

## Key Points
- **A common pattern**: many AI projects fail not because the technology is bad, but because the **project is scoped poorly** — either technically infeasible or solving something nobody needs.
- **Two very different workflows** to keep distinct:
  - **Machine learning project**: builds an AI system that learns A→B (a product feature).
  - **Data science project**: analyzes data to produce insights that inform decisions.
- **Key lesson of the week**: knowing how to select the *right* project is a skill non-technical leaders can and should build.
- **Mindset**: you don't need to be able to build AI yourself; you need to be able to **ask the right questions** and judge feasibility/value.
- **The week's arc**: understand the workflow → learn how to evaluate/choose a project → learn how to work effectively with an AI team.

## Takeaways
- Distinguish ML projects (build a model) from data science projects (produce insights).
- Good project selection depends on both **technical feasibility** and **business value**.
- A non-technical leader's job is to ask sharp questions, not to write code.
